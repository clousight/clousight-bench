**The measuring stick of [Clousight](https://clousight.com) — recognized benchmark
suites (SWE-bench Verified first), run unmodified against managed cloud products,
with a verifiable provenance chain on every number.**

Clousight Bench never re-scores a suite and never blends scores. The suite's own
harness produces the verdict; the framework adds the **cloud-product dimension**
(runtime behavior, latency, trajectory, cost) and the reproducibility bookkeeping:
which suite, which pinned dataset revision, which evaluator, which scaffold —
folded into content fingerprints you can diff.

```
BenchmarkSuite.resolve → prepare → run   (the suite's OWN harness, unmodified)
        ▼
Evaluator.evaluate(RawArtifacts)          (pure, offline, namespaced measurements)
        ▼
schema-0.3 record → csbench serve (web viewer) / csbench query (SQL)
```

Everything suite- or product-specific is a plugin.

## The reproducibility contract

Every record carries a `provenance` block (suite id, pinned dataset revision,
evaluator id, `unmodified` flag, scaffold) plus three independent fingerprints
(`benchmark` / `environment` / `implementation`), so you can tell whether two
numbers are even comparable. Every measurement carries a `reproducibility_class`:

| Class | Meaning |
|---|---|
| **deterministic** | Same inputs, same number — e.g. `swe-bench.resolved` |
| **environmental** | Method reproducible; numbers vary by network/region/account — e.g. cost, latency |
| **judge-based** | An LLM or human judgement is in the loop |

Official measurements (`official=true`) are the upstream suite's own verdict under
the suite's namespace; custom evaluators are structurally confined to their own
namespace. Results are always **per dimension — never a blended score**.

## Quick start (no cloud account, no docker)

```bash
pip install clousight-bench
csbench list                       # registered suites, evaluators, adapters

# run SWE-bench Verified through the full stage machine, in mock mode:
cat > mock.yaml <<'EOF'
target:
  mode: mock
EOF
csbench run --domain agent-runtime --benchmark swe-bench \
    --platform local-sim --config mock.yaml

# open the web viewer (EN | 中文, dark/light, trajectory waterfall):
csbench serve
```

The mock run exercises the real code path over the suite's bundled fixtures and
persists a schema-0.3 record; `csbench serve` renders it at
`http://127.0.0.1:8787`. Optional analytics store (Parquet + DuckDB):
`pip install clousight-bench[store]`.
