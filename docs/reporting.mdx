The `csbench report` command and the HTML/ECharts renderer were retired in the
**suite-first pivot (2026-08)**. Results are written as canonical JSON records
under `results/`; use `csbench query` and `csbench rollup` to inspect and
compare them.

Visualization of cross-run, cross-platform comparisons is deferred to the
Sub-project C web viewer, which will consume the same canonical JSON format.

## Query results now

```bash
# Inspect a run
csbench query "SELECT platform, task_id, status FROM records ORDER BY started_at DESC LIMIT 20"

# Compare cold-start latency across platforms
csbench query "SELECT platform, avg(value_num) AS avg_cold_start_ms FROM measurements WHERE name='cold_start_ms' GROUP BY platform"

# Export for a notebook or BI tool
csbench export measurements --out measurements.parquet
```

See [Querying results](/docs/querying) for the full DuckDB-backed analytics reference.
