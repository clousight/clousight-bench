`csbench report` 命令及 HTML/ECharts 渲染器已在 **suite-first 转型（2026-08）** 中退役。
结果以规范 JSON 记录形式写入 `results/` 目录；请使用 `csbench query` 和 `csbench rollup`
查询和对比结果。

跨运行、跨平台对比的可视化能力将由 Sub-project C Web Viewer 承接，该 Viewer 与当前 JSON 格式完全兼容。

## 现在查询结果

```bash
# 查看最近一次运行
csbench query "SELECT platform, task_id, status FROM records ORDER BY started_at DESC LIMIT 20"

# 跨平台对比冷启动延迟
csbench query "SELECT platform, avg(value_num) AS avg_cold_start_ms FROM measurements WHERE name='cold_start_ms' GROUP BY platform"

# 导出给 notebook 或 BI 工具
csbench export measurements --out measurements.parquet
```

完整的 DuckDB 分析参考见[查询结果](/docs/zh/querying)。
