# Maintainers

This file lists the people responsible for reviewing and merging changes to
Clousight Bench. See [GOVERNANCE.md](GOVERNANCE.md) for how decisions are made
and [CONTRIBUTING.md](CONTRIBUTING.md) for how to propose changes.

| Maintainer | GitHub | Areas |
|---|---|---|
| Clousight Bench maintainers | [@clousight-dev](https://github.com/clousight-dev) | core, domains, packaging, release |

## Becoming a maintainer

Contributors who land several non-trivial, well-reviewed pull requests and
consistently uphold the project's reproducibility rules (see CONTRIBUTING.md)
may be nominated as maintainers by an existing maintainer. Maintainership is
recorded by adding a row above and to [.github/CODEOWNERS](.github/CODEOWNERS).

## Contact

- Security vulnerabilities: private GitHub Security Advisory (see
  [SECURITY.md](SECURITY.md)).
- Code of Conduct reports: conduct@clousight.com (see
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)).
